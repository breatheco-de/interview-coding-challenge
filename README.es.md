## 🎯 Tu reto

Practica desafíos de código tipo entrevista con ejercicios progresivos y autoevaluación aislada en **JavaScript** o **Python**. Cada repositorio incluye retos numerados, pruebas automáticas y archivos de solución ocultos para que puedas validar tu trabajo sin depender de un entorno externo.

---

## 🌱 Cómo iniciar el proyecto

### Instalación en un clic (recomendado)

Elige la versión que quieras resolver y abre ese repositorio en Codespaces:

- **JavaScript:** [interview-coding-challenge-javascript](https://github.com/breatheco-de/interview-coding-challenge-javascript)
- **Python:** [interview-coding-challenge-python](https://github.com/breatheco-de/interview-coding-challenge-python)

### Instalación local

1. Clona o abre el repositorio del lenguaje con el que quieras trabajar:

   ```bash
   git clone https://github.com/breatheco-de/interview-coding-challenge-javascript.git
   # o
   git clone https://github.com/breatheco-de/interview-coding-challenge-python.git
   ```

2. Sigue las instrucciones de instalación del README de ese repositorio:
   - [README de JavaScript](https://github.com/breatheco-de/interview-coding-challenge-javascript)
   - [README de Python](https://github.com/breatheco-de/interview-coding-challenge-python)

---

## 💻 Qué debes hacer

- [ ] Elige si quieres practicar en **JavaScript** o **Python**.
- [ ] Abre el repositorio correspondiente (Codespaces o clonado local).
- [ ] Completa los ejercicios en orden, empezando por `exercises/00-welcome`.
- [ ] Ejecuta las pruebas de cada ejercicio antes de pasar al siguiente.

### Estructura de ejercicios

El challenge está disponible en dos repositorios separados:

1. [`interview-coding-challenge-javascript`](https://github.com/breatheco-de/interview-coding-challenge-javascript): resuelve los ejercicios en JavaScript.
2. [`interview-coding-challenge-python`](https://github.com/breatheco-de/interview-coding-challenge-python): resuelve los ejercicios en Python.

Ambos repositorios incluyen:

1. `exercises/00-welcome`: paso introductorio solo con readme.
2. `exercises/01-...` hasta `exercises/15-...`: retos de código.

Dependiendo del lenguaje elegido, la mayoría de carpetas de ejercicios incluye:

| Lenguaje   | Archivos del estudiante | Solución de referencia |
| ---------- | ----------------------- | ---------------------- |
| JavaScript | `app.js`, `tests.js`    | `solution.hide.js`     |
| Python     | `app.py`, `test.py`     | `solution.hide.py`     |

Cada ejercicio también incluye:

- `README.md`: instrucciones en inglés.
- `README.es.md`: instrucciones en español.

> **Nota:** Este repositorio es un índice que apunta a las versiones por lenguaje. Los archivos de estudiante están intencionalmente sin resolver en esos repositorios. Mantén `README.md` y `README.es.md` sincronizados cuando cambies el contenido.
